# OpenFootball Agent Toolkit v0.1.0

Prepared initial prerelease for local/private evaluation. Publication date will be
the actual GitHub release date. No established adoption or support SLA is claimed.

This version brings a self-hosted football operations workspace: players, coaches,
clubs, opportunities, mandates, twelve recruitment stages, explained player matching,
English/French/Arabic, role-based login, CSV/JSON import/export and online backups.

Matching keeps missing data separate from failures, refuses to treat an unverified
pack as eligibility confirmation, and never lets score conceal a failed condition.
All bundled examples and rules are fictional. No external data is scraped.

Requires Node.js 24, or the supplied Docker configuration after verification on your
host. Follow README for one-time owner setup. There is no default account/password.

Read docs/QUALITY-AUDIT.md for actual validation and outstanding gates. This is an
early MVP: no file uploads, email reminders, coach matching, MFA/SSO, PostgreSQL,
record-level privacy separation or measured scale guarantee. Review current
requirements with qualified professionals; the tool does not provide legal advice.

Source is Apache-2.0. The archive excludes runtime data, environment secrets and
private OpenAI application preparation. SHA256SUMS and SOURCE-MANIFEST.json identify
the source archive and commit. These are integrity aids, not a signed provenance
attestation or an independent security audit.
