# دليل البداية — OpenFootball Agent Toolkit

هذه حزمة برنامج لإدارة ملفات اللاعبين والمدربين وفرص الأندية، وليست بديلاً لموقع الوكالة.
الواجهة تدعم العربية والفرنسية والإنجليزية. البيانات تبقى في تثبيتك الخاص.

## التشغيل على حاسوبك

ثبّت Node.js من سلسلة 24، وفك ضغط الحزمة. افتح الطرفية داخل مجلد المشروع ثم نفّذ:

```sh
npm ci --ignore-scripts
npm run setup
npm run build
npm start
```

افتح http://localhost:3000/setup في المتصفح. ستجد رمز الإعداد `BOOTSTRAP_TOKEN`
داخل ملف `.env` الذي أنشأه أمر الإعداد. انسخه إلى صفحة إنشاء الحساب؛ اختر بريدك وكلمة
مرور قوية من 12 حرفًا على الأقل. لا ترسل الملف أو الرمز إلى أي شخص.

بعد إنشاء حساب المدير، سجّل الدخول وغيّر اللغة إلى العربية. يمكنك إضافة مستخدمين
بصلاحيات مدير أو محرر أو قارئ. يتيح زر الأمثلة تجربة البرنامج ببيانات خيالية فقط.
ابدأ قاعدة بيانات منفصلة للعمل الحقيقي بعد التجربة.

## الاستخدام

1. أضف الأندية ثم اللاعبين والمدربين.
2. أنشئ فرصة وحدد شروط النادي؛ لا تضع صفرًا بدل المعلومة المجهولة.
3. افتح «المطابقة» وراجع كل شرط: متحقق، غير متحقق، أو بيانات ناقصة.
4. أضف اللاعب إلى مسار التوظيف وتابع التفاوض.
5. سجّل تواريخ التفويضات؛ تظهر التفويضات النشطة التي تنتهي خلال 30 يومًا على اللوحة.
6. أنشئ نسخة احتياطية بأمر `npm run backup`، واحفظها في مكان آمن.

الرواتب شهرية وبعملة واحدة للمقارنة. لا يجري البرنامج تحويلًا للعملات.
القواعد التجريبية خيالية، ولا تثبت أهلية لاعب لدى أي اتحاد. لم نضع لوائح جزائرية أو
غيرها دون توثيق. سجلات التفويضات أدوات تنظيم؛ راجع مختصًا مؤهلًا عند الحاجة القانونية.

## النشر

المصدر متاح في [مستودع OpenFootball Agent Toolkit](https://github.com/MEHDIZEG19491/openfootball-agent-toolkit).
يمكنك تنزيله من **Code → Download ZIP**. اقرأ `docs/RELEASING.md` قبل إصدار نسخة.
يجب أن تكون قاعدة البيانات
وملفات `.env` والنسخ الاحتياطية خارج المستودع العام.

ملف إعداد طلب OpenAI منفصل وخاص، ولا يدخل في الحزمة العامة. وجود البرنامج لا يضمن
القبول؛ يجب لاحقًا توثيق الاستخدام والمساهمات والصيانة الحقيقية.

لتشغيل Docker والاستضافة الذاتية والقيود الحالية، راجع README وdocs/QUALITY-AUDIT.md.
