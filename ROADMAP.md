# Roadmap

This is a proposed sequence, not a delivery-date promise. Priorities should be
adjusted from actual pilot findings and maintainer capacity.

| Milestone                       | Outcome                                                                            | Exit evidence                                                                                                      |
| ------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| v0.1 — Core platform            | Private install, records, explained player matching, localization, imports         | Passing checks, reviewed release candidate, Docker/browser verification, documented limitations                    |
| v0.2 — Matching and rule packs  | Versioned pack distribution, coach matching, accessible pipeline board, pagination | Community-reviewed provenance and adversarial boundary fixtures; pilot workflow evidence                           |
| v0.3 — Integrations/API         | Documented external API, scoped tokens, optional PostgreSQL and adapter contracts  | Threat model, migration/restore tests, interoperability tests; no compulsory data sharing                          |
| v0.4 — Recruitment intelligence | Opt-in local operational summaries and reporting                                   | Explainable aggregate definitions, privacy review, no invented predictive certainty                                |
| v1.0 — Stable OSS release       | Stable schemas, migration commitments, accessible supported deployments            | Sustained real maintenance, independent security/accessibility review, restoration drills and real-user acceptance |

Cross-cutting priorities: safe account recovery and MFA/SSO, consent/retention and
erasure tools, keyboard/screen-reader checks, translation review, performance
measurements with stated hardware/data, documented backup restore, reproducible
releases, rule-pack review governance and additional maintainers.

No timeline, funding, contributor count or adoption is implied by this roadmap.
